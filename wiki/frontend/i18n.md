# Internationalization (i18n)

## Strategy

InfraFlowSculptor uses **ngx-translate** for runtime language switching with JSON translation files.

---

## File Structure

```
src/Front/src/assets/i18n/
├── en.json            → English (default)
└── fr.json            → French
```

---

## Key Structure

Translation keys follow a nested convention:

```json
{
  "PROJECTS": {
    "TITLE": "My Projects",
    "CREATE": "New Project",
    "EMPTY_STATE": {
      "TITLE": "No projects yet",
      "DESCRIPTION": "Create your first project to get started"
    }
  },
  "RESOURCE_EDIT": {
    "CONTAINER_APP": {
      "TITLE": "Container App",
      "FIELDS": {
        "IMAGE": "Container Image",
        "CPU": "CPU Cores",
        "MEMORY": "Memory (GB)"
      }
    },
    "DIALOG_DELETE": {
      "TITLE": "Delete Resource",
      "MESSAGE": "Are you sure you want to delete {{name}}?",
      "CONFIRM": "Delete",
      "CANCEL": "Cancel"
    }
  }
}
```

---

## Naming Conventions

| Level | Pattern | Example |
|-------|---------|---------|
| Feature | `FEATURE_NAME` | `PROJECTS`, `GENERATION` |
| Page | `FEATURE.PAGE` | `PROJECTS.LIST`, `PROJECTS.DETAIL` |
| Dialog | `FEATURE.DIALOG_NAME` | `RESOURCE_EDIT.DIALOG_DELETE` |
| Field | `FEATURE.FIELDS.NAME` | `RESOURCE_EDIT.CONTAINER_APP.FIELDS.IMAGE` |
| Action | `FEATURE.ACTIONS.NAME` | `PROJECTS.ACTIONS.CREATE` |
| Error | `ERRORS.CODE` | `ERRORS.NOT_FOUND` |

---

## Usage in Templates

```html
<!-- Simple key -->
<h1>{{ 'PROJECTS.TITLE' | translate }}</h1>

<!-- With parameters -->
<p>{{ 'RESOURCE_EDIT.DIALOG_DELETE.MESSAGE' | translate:{ name: resource.name } }}</p>

<!-- In DS components -->
<app-ds-button>
  {{ 'PROJECTS.CREATE' | translate }}
</app-ds-button>
```

---

## Usage in TypeScript

```typescript
private readonly translate = inject(TranslateService);

showConfirmation(): void {
  const title = this.translate.instant('RESOURCE_EDIT.DIALOG_DELETE.TITLE');
  // ...
}
```

---

## Rules

1. **Never hardcode strings** in templates — always use translation keys
2. **Full nested paths** for dialog keys (`RESOURCE_EDIT.DIALOG_NAME.*`)
3. **English as default** — `en.json` is the source of truth
4. **Keep keys uppercase** with dot notation
5. **Parametrize dynamic values** — `{{ 'KEY' | translate:{ param: value } }}`
